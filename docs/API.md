# API

Interactive docs: **http://localhost:8000/docs** (OpenAPI generated by FastAPI).

Authentication: `Authorization: Bearer <token>` or the `cf_session` httpOnly cookie
set by `/auth/register` and `/auth/login`.

Errors always have the shape:

```json
{"error": {"code": "rate_limited", "message": "Too many submit requests; retry in 3s",
           "details": {"bucket": "submit", "retry_after_s": 3}, "request_id": "a1b2c3d4e5f60718"}}
```

Every response carries `X-Request-ID` (echoed from the request if well-formed).

## Auth

| Method | Path | Notes |
|---|---|---|
| POST | `/auth/register` | `{username, email, password}` → 201 `{user, access_token, expires_at}`; 409 if taken; rate-limited per IP |
| POST | `/auth/login` | `{username (or email), password}` → 200; 401 `invalid_credentials`; rate-limited per IP |
| POST | `/auth/logout` | revokes the token (`jti` denylist) and clears the cookie → 204 |
| GET | `/auth/me` | current user or 401 |
| GET | `/auth/session` | `{user: … \| null}` — 200 even when logged out |

## Problems

| Method | Path | Notes |
|---|---|---|
| GET | `/problems?search=&difficulty=&tag=&status=&page=&page_size=` | cache-aside list; `status` (solved/attempted/todo) per user |
| GET | `/problems/tags` | tags with problem counts |
| GET | `/problems/{slug}` | statement, specs, constraints, limits, **sample** examples, hidden test *count*, languages + templates |
| POST | `/problems/cache/invalidate` | ADMIN: bump cache generation |

## Submissions and executions

| Method | Path | Notes |
|---|---|---|
| POST | `/submissions` | judge against all tests. Body `{problem_slug, language, source_code}`; optional `Idempotency-Key`. → **202** `{id, display_id, status, events_url, detail_url}` (200 + `idempotent_replay` on replay) |
| POST | `/executions` | "Run Code": samples, or `custom_input` if given. Never touches hidden tests. → 202 |
| GET | `/submissions?problem=&include_runs=&page=&page_size=` | caller's history |
| GET | `/submissions/{id}` (alias `/executions/{id}`) | full detail: results, attempts, transitions, source (owner/admin only; others get 404) |
| POST | `/submissions/{id}/cancel` | only from CREATED/QUEUED; 409 otherwise |
| GET | `/submissions/{id}/events` | **SSE** stream (see below) |

Status codes: 202 accepted, 401 unauthenticated, 404 not found / not yours,
409 conflict, 413 source or input > 64 KB, 422 validation (unknown language, blank
source, bad Idempotency-Key), 429 rate limited (`Retry-After`), 503 Postgres/Redis
unavailable (`Retry-After`).

### SSE events

```
event: snapshot        data: {…submission detail without source…}
id: 1793018469621-0
event: queued          data: {"type":"queued","mode":"SUBMIT","language":"cpp","ts":…}
event: claimed         data: {"worker_id":"worker-ab12cd34-1","attempt":1,"queue_wait_ms":12,"tests":17}
event: sandbox_ready   data: {"ms":412,"container":"cf-sbx-1927-1-3fa2c1"}
event: compiling
event: compiled        data: {"ok":true,"ms":143}
event: status          data: {"status":"RUNNING"}
event: running         data: {"tests":17}
event: test            data: {"index":1,"verdict":"ACCEPTED","cpu_ms":21,"wall_ms":22,"memory_kb":3500,"sample":true}
…
event: judging
event: completed       data: {"verdict":"ACCEPTED","runtime_ms":29,"memory_kb":3720,"passed":17,"total":17,"total_ms":1180}
event: snapshot        data: {…final state…}
event: end
```

Also possible: `retrying` (`attempt`, `reason`), `internal_error`, `cancelled`.

## Users and stats

| Method | Path | Notes |
|---|---|---|
| GET | `/users/me/profile` | solved counts by difficulty, recent accepted |
| GET | `/users/{username}` | public profile (no source code) |
| GET | `/users/leaderboard?limit=` | cached 30 s |
| GET | `/stats/overview` | landing numbers (cached 10 s) + live worker count |

| Method | Path | Notes |
|---|---|---|
| GET | `/health` | liveness |

## Example

```bash
TOKEN=$(curl -s localhost:8000/auth/register -H 'content-type: application/json' \
  -d '{"username":"ada","email":"ada@example.com","password":"correct-horse"}' | jq -r .access_token)

ID=$(curl -s localhost:8000/submissions -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -H "Idempotency-Key: demo-$(date +%s)" \
  -d '{"problem_slug":"two-sum","language":"python","source_code":"print(0, 1)"}' | jq .id)

curl -N localhost:8000/submissions/$ID/events -H "Authorization: Bearer $TOKEN"
```
